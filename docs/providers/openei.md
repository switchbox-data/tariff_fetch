# OpenEI

## Credentials

Set the `OPENEI_API_KEY` environment variable before running the CLI (export it or place it in your `.env` file):

```bash
OPENEI_API_KEY=...
```

## Obtaining Access

1. Request an API key via the [OpenEI API signup form](https://openei.org/services/api/signup/).
2. The key is emailed to you. Copy it into `OPENEI_API_KEY`.
