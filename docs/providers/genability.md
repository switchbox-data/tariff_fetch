# Genability / Arcadia

## Credentials

Set the following environment variables before invoking the CLI (usually via your shell or a `.env` file):

```bash
ARCADIA_APP_ID=...
ARCADIA_APP_KEY=...
```

## Obtaining Access

1. [Create an account](https://dash.genability.com/signup) if you do not already have Arcadia credentials.
2. Navigate to the [Applications dashboard](https://dash.genability.com/org/applications).
3. Create a new application, then copy the Application ID and Key into the environment variables above or add them to your `.env` file.
